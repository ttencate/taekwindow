title: Deprecating taekwindow.net
---

Taekwindow hasn't had any updates in (checks notes) 17 years, and chances are that nobody is using it anymore. It's time for me to stop paying for the domain name.

Still, I'd like not to remove it suddenly, so I'll install a redirect to [ttencate.github.io/taekwindow](https://ttencate.github.io/taekwindow) and keep that active for a year, so that search engines may pick up the new site.

After that year (some time in March 2027), I'll let the domain `taekwindow.net` expire.

I no longer use Windows at all, so I will not be maintaining this project any further. There is some sweet irony in keeping the free hosting by GitHub now that it's owned by Microsoft, since it was Microsoft's shortcomings that prompted me to create Taekwindow in the first place.
